BEYOND THE PERFORMANCE — LANDING PAGE

Files
- index.html: main event landing page
- register.html: registration form that opens WhatsApp with the submitted details prefilled
- styles.css: responsive styling in cream, red and black
- script.js: copy-account-number button and WhatsApp registration flow
- assets/event-poster.jpg: supplied event poster

How to preview
1. Extract the ZIP.
2. Open index.html in a browser. For best testing, use VS Code with the Live Server extension.
3. Click Register now to test the registration form.

Important notes
- The form does not save data to a database. It prepares a WhatsApp message for the attendee to send.
- The registration message opens WhatsApp to +234 704 594 8927. The attendee should attach their payment receipt/proof manually in the WhatsApp chat.
- No event fee was supplied, so the page does not invent one. Confirm the amount with the organisers before transferring.
- Before publishing, confirm the event details, account name, and payment amount. To make the form store registrations automatically, connect it to a backend/database and add appropriate privacy/security handling.
